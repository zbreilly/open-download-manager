# Store listing images

Pictures for the extension's pages on addons.mozilla.org and the Chrome Web Store.

- `icon-128.png`: the add-on icon.
- `promo-small-440x280.jpg`: the small promo tile the Chrome Web Store asks for.
- `screenshot-1-overview.jpg` to `screenshot-4-themes.jpg`: 1280 × 800 screenshots, in the order they should appear. The second one comes in two versions: `screenshot-2-popup-firefox.jpg` for addons.mozilla.org and `screenshot-2-popup-chromium.jpg` for the Chrome Web Store and Edge Add-ons. They differ only in the browser the popup names.

The popup in the second screenshot is the extension's own popup page drawn with sample data. The app windows are screenshots of version 0.2.0 with demo downloads.
