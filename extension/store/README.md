# Store listing images

Pictures for the extension's pages on addons.mozilla.org and the Chrome Web Store.

- `icon-128.png`: the add-on icon.
- `screenshot-1-overview.jpg` to `screenshot-4-themes.jpg`: 1280 × 800 screenshots, in the order they should appear.

The popup in `screenshot-2-popup.jpg` is the extension's own popup page drawn with sample data. The app windows are screenshots of version 0.2.0 with demo downloads.
